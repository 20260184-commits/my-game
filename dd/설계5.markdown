## 3. 콤보 시스템 (Combo System) - 업데이트

### ① 시간 기반 콤보 유지 (Time-based Combo Window)
기존의 '경직 상태 체크' 방식에서 **'시간 윈도우'** 방식으로 변경하여, 훨씬 유연하고 공격적인 플레이가 가능하게 합니다.

*   **콤보 윈도우 (Combo Window):** 마지막 타격 성공 후 **약 0.5초(30프레임)** 이내에 다음 타격이 적중하면 콤보가 유지됩니다.
*   **유지 로직:** `Last_Hit_Time` 기록 $\rightarrow$ `Current_Time - Last_Hit_Time < 30f` $\rightarrow$ `Combo_Count++`
*   **초기화 조건:**
    1.  콤보 윈도우(30f)가 종료될 때까지 다음 공격이 적중하지 않은 경우.
    2.  공격이 완전히 헛쳤을(Whiff) 때 (단, 헛친 직후 콤보 윈도우 내에 다른 공격으로 보완 가능).

### ② 콤보 스케일링 (Scaling)
| 콤보 횟수 | 데미지 보정 | 경직 시간 보정 | 후딜레이 보정 (Fatigue) |
| :--- | :---: | :---: | :---: |
| **1 ~ 2 Hit** | 100% | 100% | 기본값 |
| **3 ~ 4 Hit** | 90% | 90% | +1~2f 증가 |
| **5 Hit+** | 70% $\rightarrow$ 40% | 70% $\rightarrow$ 40% | +3~5f 증가 (캔슬 필수 구간) |

## 4. 핵심 전투 메커니즘 (심화)

### ① 다이나믹 카메라 및 가상 벽 (Dynamic Camera & Virtual Wall)
*   **카메라 작동:** `Camera_X = (Player_X + Enemy_X) / 2`
*   **화면 끝 벽 판정 (Screen-Edge Collision):**
    *   두 캐릭터 사이의 거리(`abs(Player_X - Enemy_X)`)가 **화면 너비의 80% (약 1000px)**에 도달하면, 그 지점을 즉시 **벽(Wall)**으로 인식합니다.
    *   이 상태에서 더 멀어지려는 입력은 무시되며, 벽 튕김(Knockback) 판정이 적용됩니다.
    *   **효과:** 맵 전체를 돌아다닐 수 있지만, 전투 시에는 항상 서로를 화면 안에 가두어 긴장감을 유지합니다.

### ② 대쉬 및 캔슬 시스템 (Dash & Cancel)
*   **입력 방식:** 방향키 빠르게 두 번 입력.
*   **히트 게이지:** 공격 성공 3회 시 대쉬 1회 충전.
*   **대쉬 캔슬:** 후딜레이 증가로 인해 콤보 템포가 밀리는 구간에서 대쉬를 사용해 후딜을 강제로 삭제하고 위치를 재잡아 콤보를 연장합니다.

### ③ 방향성 가드 (Directional Guard)
*   **입력 방식:** 적을 등지고 방향키 입력.
*   **효과:** 데미지 50% 감소 $\rightarrow$ 가드 전용 경직 적용 $\rightarrow$ 콤보 윈도우 초기화.

## 6. 업데이트된 개발 구현 가이드 (코드 적용 포인트)

### 🛠️ 구현 핵심 로직 (Pseudo Code)

**1. 카메라 및 가상 벽 구현**
```python
# 매 프레임 업데이트
cam_x = (player.rect.centerx + enemy.rect.centerx) / 2 - SCREEN_WIDTH // 2
max_dist = SCREEN_WIDTH * 0.8

# 플레이어 이동 제한 (가상 벽)
if player.rect.centerx - enemy.rect.centerx > max_dist:
    player.rect.centerx = enemy.rect.centerx + max_dist
elif player.rect.centerx - enemy.rect.centerx < -max_dist:
    player.rect.centerx = enemy.rect.centerx - max_dist
```

**2. 시간 기반 콤보 윈도우 구현**
```python
# 히트 시점
if collision:
    current_time = pygame.time.get_ticks()
    if current_time - self.last_hit_time < 500: # 0.5초 윈도우
        self.combo_count += 1
    else:
        self.combo_count = 1
    self.last_hit_time = current_time
```

**3. 황금 밸런스 후딜레이 적용**
```python
# 공격 종료 시 recovery_timer 설정
base_recovery = 10 if atk_type == "LIGHT" else 15
fatigue_penalty = (self.combo_count * 1) if atk_type == "LIGHT" else (self.combo_count * 2)
self.recovery_timer = base_recovery + fatigue_penalty
```

### 💡 설계 의도 요약
1.  **카메라:** 맵의 물리적 한계를 없애 자유도를 높였지만, '화면 끝'이라는 심리적/시스템적 벽을 통해 격투 게임 특유의 거리 조절(Spacing) 재미를 유지했습니다.
2.  **콤보:** '경직 상태'라는 까다로운 조건 대신 '시간'이라는 직관적인 조건을 부여하여, 플레이어가 더 과감하게 공격 버튼을 누를 수 있게 했습니다.
3.  **밸런스:** 후딜레이를 아주 조금씩만 증가시켜, 초보자는 그냥 연타해도 콤보가 나가지만, 고수는 대쉬 캔슬을 섞어 무한에 가까운 화려한 콤보를 넣을 수 있는 '숙련도 차이'를 만들었습니다.
